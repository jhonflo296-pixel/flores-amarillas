# 🌻 Galaxia de Flores Amarillas para Isabel

Una experiencia interactiva 3D con Three.js dedicada para el Día de las Flores Amarillas.

✨ **Características:**
- Agujero negro central con resplandor dorado y anillo estilo Saturno.
- Girasol y ramos de flores amarillas orbitando en el espacio 3D.
- Más de 150 frases de cariño flotando en el espacio.
- Vista 3D interactiva con soporte para rotación táctil, ratón y zoom.
- Música de fondo opcional al pulsar "Toca para iniciar".
